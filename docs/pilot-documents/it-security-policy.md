# Information Technology Security Policy

All employees must use strong passwords and must not share their passwords with other people.

Passwords should contain at least 12 characters and should not contain easily guessable information such as the employee's name, date of birth, or company name.

## Multi-Factor Authentication

Multi-factor authentication is required for company systems that support it.

Employees must not approve authentication requests that they did not initiate.

## Access Control

Company systems must only be accessed using authorized accounts. Employees must immediately report suspected unauthorized access to the IT security team.

## Security Incidents

Security incidents, lost company devices, suspected phishing attempts, and accidental disclosure of company information must be reported to the IT security team as soon as possible.
