# IT Acceptable Use Policy — NovaWorks Technologies

## Document Info
- **Document ID:** POL-IT-001
- **Owner:** IT & Information Security
- **Last Reviewed:** September 2026
- **Applies to:** All employees, contractors, and interns with access to company systems

## 1. Purpose
This policy governs acceptable use of NovaWorks-owned devices, software, network, and internet/email resources to protect company data and systems from misuse, security risk, and legal liability.

## 2. Device Usage Rules
- Company laptops are for business use; **reasonable incidental personal use** (checking personal email, light browsing) is permitted.
- Devices must have full-disk encryption, the company-managed antivirus/EDR agent, and auto-lock after 5 minutes of inactivity — all enforced automatically via Mobile Device Management (MDM).
- Do not disable, uninstall, or tamper with MDM, antivirus, or security agents installed on company devices.
- Lost or stolen devices must be reported to IT **within 2 hours** of discovery via the Ethics Hotline or an urgent IT ticket, so the device can be remotely wiped/locked.
- Personal devices (BYOD) accessing company email/Slack must be enrolled in MDM (mobile app management profile) before access is granted.

## 3. Software Installation Rules
- Only software from the **IT-approved software catalog** (available in NovaWorks Desk — IT Module) may be self-installed.
- Installing software outside the catalog requires a request via IT ticket, including business justification; Security reviews any tool that would access company data.
- Pirated, cracked, or unlicensed software is strictly prohibited on any company device.
- Browser extensions requesting broad data access are blocked by default; exceptions require IT Security approval.
- Admin/root access on company laptops is restricted by default; developers needing local admin rights request it via a scoped, time-limited IT ticket.

## 4. Internet & Email Usage
- Company internet access is monitored for security purposes (not for general productivity monitoring); usage logs are retained per the Information Security & Data Protection Policy.
- Accessing illegal content, torrenting copyrighted material, or bypassing web filtering/proxy is prohibited.
- Company email must not be used for personal business ventures, chain messages, or unsolicited bulk email.
- Auto-forwarding company email to a personal email account is disabled by default and requires a documented exception approved by your manager and IT Security.
- Suspicious emails (phishing attempts) should be reported using the "Report Phishing" button in the email client, not simply deleted.

## 5. Prohibited Activities
- Sharing login credentials with anyone, including colleagues.
- Connecting unapproved USB storage devices to company laptops (USB ports are restricted by default policy).
- Using company systems to harass, discriminate, or violate the Code of Conduct.
- Circumventing security controls (VPN bypass, disabling firewall, using unauthorized proxies).

## 6. Consequences of Violation
Violations are handled per the disciplinary framework in the Employee Handbook, ranging from a warning and mandatory re-training to immediate termination and, for serious breaches (e.g., data exfiltration), legal action.

## Common Questions
- **"Can I install [some app] on my work laptop?"** → Check the IT-approved software catalog first; if not listed, raise an IT ticket with justification.
- **"What do I do if I lost my laptop?"** → Report immediately (within 2 hours) via an urgent IT ticket so it can be remotely wiped.
- **"Can I forward my work email to my personal Gmail?"** → Not by default; requires manager + IT Security approval as a documented exception.

*This document should ground device/software/email usage questions. For VPN access and data classification, see the Information Security & Data Protection Policy.*
